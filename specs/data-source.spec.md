## 二、trade.500.com 规格

### 2.1 比赛列表页

**URL**: `https://trade.500.com/jczq/?playid=269&g=2&date={YYYY-MM-DD}`

**前置条件**:
1. 必须先访问 `https://trade.500.com/` 首页获取Cookie，否则返回403
2. 使用 `requests.Session` + 完整浏览器请求头

**请求头**:
```
User-Agent: Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36
Accept: text/html,application/xhtml+xml,...
Accept-Language: zh-CN,zh;q=0.9,en;q=0.8
Accept-Encoding: identity
Connection: keep-alive
```

**解析方式**: BeautifulSoup解析 `<tr>` 标签的 `data-matchnum` 属性

**关键约束**:
- 页面同时包含周六和周日比赛，用 `data-matchnum` 区分（如 `周日001`、`周六026`）
- 不能用关键字"周六"/"周日"在HTML中的位置判断归属
- 页面编码GBK，需 `content.decode('gbk', errors='ignore')`

**输出结构**:
```json
{
  "matchnum": "周日001",
  "fid": "1373080",
  "home": "全北现代",
  "away": "浦项制铁",
  "league": "韩职",
  "time": "13:00",
  "rq": "-1"
}
```

### 2.2 欧赔详情页

**URL**: `https://odds.500.com/fenxi/ouzhi-{fid}.shtml`

**提取内容**: 竞彩官方(cid=1)、Interwetten(cid=4)、百家平均的三组初盘+即时赔率

**格式**: 初盘胜/初盘平/初盘负 + 即时胜/即时平/即时负 + 盘路变化方向

### 2.3 亚盘详情页

**URL**: `https://odds.500.com/fenxi/yazhi-{fid}.shtml`

**提取内容**: 澳门、立博、皇冠等公司的初盘/即时盘口+水位

**盘口描述**: 中文名称（如 `一球/球半`、`平手`），需去掉"升""降"后缀

### 2.4 让球详情页

**URL**: `https://odds.500.com/fenxi/rangqiu-{fid}.shtml`

**提取内容**: 竞彩官方让球初盘+即时赔率

### 2.5 投注数据页

**URL**: `https://trade.500.com/touzhu-{fid}.shtml`

**提取内容**: 各方向投注占比 + 庄家盈亏值（可能为负数）

### 2.6 同赔查询接口

| 接口 | 参数 | 用途 |
|------|------|------|
| 竞彩: `https://odds.500.com/fenxi/ouzhi/1/{fid}.shtml?cid=1&...` | 初盘赔率 | 查询竞彩同赔历史 |
| IW: `https://odds.500.com/fenxi/ouzhi_sameajax.php?cid=4&...` | 初盘赔率 | 查询Interwetten同赔历史 |
| 让球: `rangqiu_sameajax.php` | 初盘让球赔率 | 查询让球同赔历史 |
| 澳门亚盘: `yazhi_sameajax.php` | 初盘盘口+水位 | 查询澳门亚盘同赔历史 |

**同赔查询规则**: 全部使用**初盘**参数，不使用即时盘

## 三、odds.500.com 规格

### 3.1 赔率页面通用模板

```
https://odds.500.com/fenxi/{type}-{fid}.shtml
```

其中 `type` 取值: `ouzhi`(欧赔), `yazhi`(亚盘), `rangqiu`(让球)

### 3.2 百家欧赔提取

**来源**: 欧赔详情页

**提取规则**: 20+家公司的初盘/即时赔率，按公司分组

**对比规则**:
- 三项（主胜、平局、客胜）全部参与对比
- **至少两项**符合即匹配
- 整数+小数点第一位一致即匹配（如1.39→1.3，1.30→1.3）
- 不允许上下浮动，必须精确匹配

## 四、liansai.500.com 规格

### 4.1 球队赛程页

**URL**: `https://liansai.500.com/team/{TEAM_ID}/teamfixture/`

**数据格式**: `<tr data='{...}'>` 中的JSON

**筛选规则（3层过滤）**:
1. **主客场**: 根据查询目标筛选（主队查主场，客队查客场）
2. **联赛**: `SIMPLEGBNAME == 本场比赛联赛名称`
3. **盘口**: `HANDICAPLINENAME == 第6步澳门即时盘口`

**轮次选取规则**:

| 当前轮次 | 选取策略 | 示例 |
|---------|---------|------|
| > 20轮 | 从上一轮开始往前推20轮 | 当前35轮 → 取第34~15轮 |
| 11~20轮 | 取本赛季全部历史轮次 | 当前13轮 → 取第1~12轮 |
| ≤ 10轮 | 前一赛季取19轮 + 本赛季第1轮 | 当前2轮 → 取上赛季最后19轮 + 本赛季第1轮 |

**跨赛季说明**: 当前轮次 ≤ 10 时需跨赛季取数，注意不同赛季联赛ID可能不同

## 五、数据质量约束

### 5.1 报告质量检查

| 指标 | 正常范围 | 空洞标记 |
|------|---------|---------|
| 报告大小 | 30-45KB | 10-12KB（空洞报告，等同失败） |
| 来源获取 | 至少1条有效来源 | 0条（需标记⚠️） |
| 比赛场次 | 匹配数据源列出的场次 | 缺失场次需标记 |

### 5.2 错误处理原则

1. **失败必须显式标记**（⚠️），不允许静默通过
2. 数据质量问题必须输出FLAG通知，不能仅记日志
3. 搜索获取失败/返回0场时，必须在输出中标记
4. 空洞报告（10-12KB vs 正常30-45KB）等同失败处理
